# Distribution plan (platforms actually available)

Honest starting point: the first live had one viewer, the owner's second account. No schedule or tactic guarantees an audience; this plan makes each stream produce material to be found with.

1. **YouTube Live**: fixed weekly slot once the experience is verified on an unlisted run; title in search terms ("Prop firm drawdown explained, live Q&A"), tracked link in the description and pinned comment.
2. **Replays**: leave the broadcast public as a replay with chapters from the rundown blocks.
3. **YouTube Shorts**: 3 to 8 reviewed clips per stream from `live-host:clips`, one idea each, captions checked, tracked link `utm_content=short`. Published only after the owner approves each one.
4. **Existing Fillbook accounts**: link the replay from the channels the owner already runs, by hand.
5. **Communities** (r/FillbookHQ, Discord, relevant subreddits where self-promotion is allowed): one honest post per replay with what is in it, never automated, never unsolicited messages.
6. **Website**: a "Watch Tilt live" mention near the tracked landing page only after a run shows people arrive from it.

Not done by the system: publishing, posting, messaging. Everything above is a human step behind approval.
